# Инструкция по установке и использованию

## Установка

1. Убедитесь, что у вас установлен Python версии 3.8 или выше. Вы можете скачать его с официального сайта: [https://www.python.org/](https://www.python.org/).

2. Склонируйте репозиторий или скачайте файлы проекта в удобную для вас директорию.

3. Откройте терминал и перейдите в директорию проекта. Например:
   ```powershell
   cd d:\LZT\free04
   ```

4. Установите необходимые зависимости, выполнив следующую команду:
   ```powershell
   pip install -r requirements.txt
   ```

## Использование

1. Убедитесь, что файл `user.txt` содержит корректные данные для входа. Пример содержимого файла:
   ```
   login:passworld
   ```

2. Запустите скрипт `main.py` с помощью следующей команды:
   ```powershell
   python main.py
   ```

3. Следуйте инструкциям, отображаемым в консоли.

## Примечания

- Если у вас возникли проблемы с установкой зависимостей, убедитесь, что у вас есть доступ в интернет и корректно настроен Python.
- Для изменения данных пользователя отредактируйте файл `user.txt`.
- Если вы используете виртуальное окружение, активируйте его перед установкой зависимостей.
